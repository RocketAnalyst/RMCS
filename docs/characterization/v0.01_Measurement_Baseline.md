# RMCS V0.01 Measurement Baseline

This document records the initial measurement characterization of the
RMCS V0.01 hardware and firmware.

The purpose of this baseline is to establish the behavior of the
measurement system before making future hardware or software changes.

---

## Test 007 — Zero-Load Stability

**Date:** 2026-09-15  
**Firmware:** RMCS V0.01  
**Test file:** TEST_007.CSV

### Hardware

- Teensy 4.1
- SparkFun HX711 load-cell amplifier
- 1-ton button/disc load cell
- Built-in Teensy 4.1 microSD card
- V0.01 firmware

### Acquisition Performance

| Measurement | Result |
|---|---:|
| Total samples | 5,804 |
| Total recording duration | 68.388 s |
| Measured sample rate | 84.85 SPS |
| Approximate sample interval | 11.78 ms |

The sample rate was calculated from the actual timestamps recorded
in the CSV rather than assuming the nominal HX711 rate.

---

## Zero-Load Stability

The load cell was tared with no external load and then monitored for
approximately 60 seconds before a controlled mechanical load was
applied.

### Results

| Measurement | Result |
|---|---:|
| Zero-load samples | 5,090 |
| Zero-load duration | ~60 s |
| Mean force | -0.017 N |
| Standard deviation | 0.419 N |
| RMS noise | 0.419 N |
| Minimum | -1.907 N |
| Maximum | +1.571 N |
| Peak-to-peak range | 3.478 N |
| Estimated drift | ~0.131 N/min |

The unloaded measurement remained centered very close to zero
throughout the test.

The approximately 0.42 N standard deviation represents the observed
V0.01 measurement noise under these test conditions.

---

## Zero-Load Stability by Time Segment

The approximately 60-second unloaded period was divided into
10-second intervals.

| Time | Mean Force | Standard Deviation |
|---|---:|---:|
| 0–10 s | -0.121 N | 0.428 N |
| 10–20 s | -0.007 N | 0.411 N |
| 20–30 s | -0.016 N | 0.399 N |
| 30–40 s | +0.001 N | 0.415 N |
| 40–50 s | +0.027 N | 0.423 N |
| 50–60 s | +0.015 N | 0.423 N |

The first approximately 10 seconds showed a small negative offset,
after which the baseline remained relatively stable.
