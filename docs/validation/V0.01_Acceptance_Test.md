# RMCS V0.01 Acceptance Test

## Purpose

This document records the final controlled-load acceptance test for the RMCS V0.01 firmware and measurement/data-acquisition system.

The purpose of this test was to verify the complete V0.01 acquisition workflow using a controlled bench load before proceeding to further test-stand development.

This test did not involve rocket motor ignition or pyrotechnic activity.

---

## Firmware

- System: ROCI Motor Characterization System (RMCS)
- Firmware Version: V0.01
- Microcontroller: Teensy 4.1
- Load-cell amplifier: SparkFun HX711
- Load cell: 1-ton button/disc load cell
- Storage: Teensy 4.1 built-in microSD
- Calibration: 226.0 counts/N
- Nominal acquisition rate: approximately 85 samples/second

---

## Acceptance Test

### Test File

`TEST_008.CSV`

### Test Procedure

The test was performed using a controlled bench load to simulate the sequence of:

1. No load / baseline
2. Applied load
3. Sustained load
4. Load removal
5. Post-load recording

The physical TARE and START controls were used.

No manual state transitions were required. RMCS V0.01 automatically detected the transition into the BURNING state when the measured load exceeded the configured ignition threshold and detected burnout when the measured load returned below the configured burnout threshold.
